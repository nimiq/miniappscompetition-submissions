## Description

GAZE is an Arbitrum USDT portfolio manager for Nimiq Pay. Pick your risk: Conservative (Aave V3 lending), Balanced (50% protected reserve), or Aggressive (GMX V2 ETH trading). Smart contracts and wallet signatures enforce all limits. The app currently runs in simulated beta.
